# Reinforcement Learning Experiments

## About This Repository

This repository contains the laboratory experiments and practical implementations completed as part of the **Reinforcement Learning** course.

The experiments focus on understanding reinforcement learning concepts, implementing algorithms, analysing agent behaviour, and exploring how an agent learns to make decisions through interactions with an environment.

## Objectives

- Understand the fundamental concepts of Reinforcement Learning.
- Implement reinforcement learning algorithms using Python.
- Explore states, actions, rewards, policies, and value functions.
- Understand how agents learn through trial and error.
- Analyse the performance and behaviour of learning algorithms.
- Apply reinforcement learning concepts to practical problems.

## Technologies Used

- **Programming Language:** Python
- **Libraries:** NumPy, Matplotlib, and other libraries used in individual experiments
- **Tools:** Jupyter Notebook / Google Colab / VS Code

## Experiments

This repository is organised experiment-wise for easy understanding and reference.

Each experiment includes:
- Aim
- Algorithm or procedure
- Implementation / source code
- Output
- Result and observations

## Key Concepts Covered

- Reinforcement Learning fundamentals
- Markov Decision Processes (MDPs)
- States, actions, and rewards
- Policies and value functions
- Exploration and exploitation
- Monte Carlo methods
- Policy evaluation and control
- Other algorithms covered in the laboratory syllabus

*The concepts listed above will be updated according to the experiments included in this repository.*

## Learning Outcomes

Through these experiments, I aim to develop a practical understanding of reinforcement learning algorithms, their implementation, and their applications in sequential decision-making problems.
